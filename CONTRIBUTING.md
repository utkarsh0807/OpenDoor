# Contributing to OpenDoor

Thank you for your interest in improving OpenDoor!

## Development Workflow
1. Install project packages: `npm install`
2. Start development server: `npm run dev`
3. Execute automated test suites: `npm run test`
4. Verify production build: `npm run build`

## Code Standards
- Keep business logic decoupled from presentation.
- Retain strict source provenance on all opportunity records.
- Ensure all new features have test coverage in `src/tests`.
